# Еда (этап 4, часть)

Концепция: [2026-10-20-body-diary-concept.md](2026-10-20-body-diary-concept.md). Вода и ИИ-оценка калорий — позже.

## Ввод

- Свободный текст без команды: «обед 650», «перекус 2 яблока 190», «ужин: паста 820 ккал», «вчера ужин 700». Разбор — `parseFoodLine` (`src/utils/food.ts`, тесты): число ккал в конце (20–5000), хотя бы одна буква; первое слово «завтрак/обед/ужин/перекус» — приём пищи; «вчера» в начале — запись на вчера. Одно число без слов едой не считается.
- Текстовый обработчик еды зарегистрирован **самым последним**: берёт только текст, который не забрал ни один сценарий; во время записи тренировки текст едой не считается. Нераспознанный текст — подсказка по форматам.
- Висящий утренний вопрос про сон/вес не мешает: строка, похожая на еду, уходит в модуль еды.
- После записи — «✏️ Ккал» (новое число) и «🗑 Удалить».

## Данные и расчёты

- `food_entries (user_id, eaten_on date — местная дата, meal, description, kcal)`.
- Норма — Миффлин — Сан-Жеор × 1,375 (лёгкая активность), цель: −500 / +300 / 0, не ниже BMR, кратно 25; вес — последний записанный.
- Средние за 7 и 30 дней — по дням, где есть записи (`averagePerDay`).
- «Частые блюда» — записи с описанием за 30 дней, встречавшиеся ≥2 раз; ккал из последней. Кнопками в `/food` и в режиме «еда за вчера». Отдельной таблицы шаблонов блюд нет.

## Где видно

- `/food` — записи за сегодня (правка/удаление), итог против нормы, средние, частые блюда, «📅 Еда за вчера».
- `/today` — строка «🍽 Еда: X / норма ккал».
- Утренний обзор «вчера» — строка с итогом за вчера и кнопка «🍽 Еда за вчера» (режим ввода за дату до «✅ Готово»).

## ИИ-оценка калорий (добавлено 2026-10-20)

- Текст без числа ккал, похожий на описание еды (`looksLikeFoodDescription`: ≥3 буквы подряд, до 200 символов), при включённом модуле еды и заданном `GEMINI_API_KEY` уходит в Gemini (`src/ai/foodEstimate.ts`). Префиксы «вчера» и приём пищи снимаются заранее (`parseFoodPrefix`).
- Ответ — JSON `{isFood, name, portion, kcal, proteinG}`, проверяется `parseEstimate` (ккал 20–5000). Не еда → обычная подсказка.
- Кнопки: «✅ Записать», «✏️ Своё число» (ждём ккал для этого описания), «❌ Не то». Белок показывается, но не хранится.
- Модель: `GEMINI_MODEL` или `gemini-flash-latest` → `gemini-2.5-flash` → `gemini-flash-lite-latest`; на 404/400 (кроме ошибки ключа) пробуется следующая. 429 → сообщение о лимите.
- Лимит 40 оценок на пользователя в день (в памяти процесса) — бережём общий бесплатный лимит ключа.
- Висящий вопрос сна/веса пропускает текст-описание еды без цифр дальше, в модуль еды.
- Приватность: на бесплатном тарифе Google может использовать запросы для улучшения моделей — уходит только описание еды, без имени и id.
