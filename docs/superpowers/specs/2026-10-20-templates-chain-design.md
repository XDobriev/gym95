# Шаблоны тренировок и цепочка (часть этапа 3)

Концепция: [2026-10-20-body-diary-concept.md](2026-10-20-body-diary-concept.md). Сделано срочно к ближайшей тренировке владельца, поэтому часть этапа 3 отложена (см. «Не вошло»).

## Шаблоны

- Таблица `workout_templates`: `user_id null` + `slug` — готовые шаблоны для всех, иначе личные. Поля `exercises` (jsonb, подходы `{weight, reps}`; weight 0 — свой вес; у планки reps — секунды) и `cardio` (`{activity, durationMinutes, distanceKm}`). `rotation_group/rotation_order` задают чередование.
- Готовые: «Фулбади A», «Фулбади B» (чередование `fullbody`), «Дом» (свой вес, по одному подходу), «Стадион» (ходьба 48 мин / 4 км). Сидятся в `migrations/schema.sql` через `on conflict (slug) do update` — правка состава = правка миграции и повторное применение.
- `workouts.template_id` связывает тренировку с шаблоном.
- **Подстановка:** при выборе шаблона черновик заполняется упражнениями/кардио последней тренировки пользователя по этому шаблону, а если её нет — значениями шаблона. Так шаблон «персонализируется» сам, отдельного редактирования готовых шаблонов нет.
- **Поток `/new_workout`:** первый экран — выбор шаблона (первым — следующий по чередованию фулбади), «🆕 С нуля» (старый выбор типа), «📅 Другая дата». Затем экран шаблона: правка подходов упражнения (ввод заменяет подходы), удаление, «Время и км» для кардио, «➕ Добавить упражнение» (переводит в обычный поток; кардио-шаблон становится смешанной тренировкой), «✅ Сохранить».
- **Свои шаблоны:** под итогом тренировки без шаблона — «💾 Сохранить как шаблон» → название текстом. `/templates` — список и удаление своих.

## Цепочка

- Модуль `activity` стал доступным (`available: true`), блок в `/today`.
- Цепочка — подряд идущие дни тренировок с перерывом не более `maxGapDays` дней отдыха (1–3, по умолчанию 2); несколько тренировок в день — один день. Учитываются все тренировки, включая записанные задним числом. Чистая функция `computeChain` (`src/utils/chain.ts`, тесты рядом).
- Цель (`chainGoal`, по умолчанию из стартового набора цели, 2–365) и перерыв — `/settings → Тренировки → 🔗 Цепочка`.
- После сохранения тренировки — строка цепочки; ровно при достижении цели — поздравление.

## Не вошло (следующие шаги)

- Подсказка прогрессии («в прошлый раз все подходы — попробуй +2,5 кг»).
- Вечернее напоминание «сегодня последний день сохранить цепочку».
- Редактирование состава своего шаблона (сейчас — удалить и сохранить заново).
- Отметки галочками для «Дома» (сейчас — тот же экран шаблона с правкой повторений).
